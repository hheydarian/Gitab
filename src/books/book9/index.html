Prompt Engineering for LLMs

مهندسی پرامپت برای مدل‌های زبانی بزرگ

هنر و علم ساخت برنامه‌های کاربردی نسل جدید با مدل‌های زبانی بزرگ (LLM)؛ از مفاهیم پایه‌ای ترنسفورمر تا معماری RAG و عامل‌های هوشمند خودمختار.

مدل‌های زبانی بزرگ (LLMs) جهان مهندسی نرم‌افزار را متحول کرده‌اند. این اثر برجسته از متخصصان برجسته گیت‌هاب کوپایلوت و پژوهشگران اورایلی، جادوی پشت این مدل‌ها را کنار زده و با چارچوبی ساختاریافته به شما می‌آموزد که چگونه از توکن‌ها، قالب‌های ساختاریافته، تکنیک‌های Few-Shot، معماری RAG و عامل‌های تصمیم‌گیرنده برای حل مسائل واقعی استفاده کنید.
